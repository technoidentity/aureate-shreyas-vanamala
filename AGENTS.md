# Repository review guidance

Read `CONTRIBUTING.md` before preparing commits or pull requests. Its guidance records recurring feedback from PR #1.

- Use specific, complete commit subjects; keep unrelated changes separate.
- Keep Cargo binaries complete and compilable, and every package supplied with a source target.
- Use Markdown for new study snippets and notes; preserve existing documents unless asked to convert them.
- Run the applicable package and game checks in `CONTRIBUTING.md`, and report actual results.
- Keep PR titles and descriptions aligned with the final scope. Weekly learning titles use `Learning Progress: Week N - Topics`; never guess the week number.
- Do not claim CI passed based only on local checks. Do not rewrite published commits solely to improve their subjects.
